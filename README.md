# desktop-publishing-2-task-5
1. Open **Practical-5-Astral-Tides.psd** in Photoshop.
2. Rename **Layer 1** to `Eclipse Artwork`.
3. Add a new layer named `Eclipse Glow`. Use a large, soft orange brush to paint over the eclipse, then set the layer blend mode to **Screen** and lower its opacity.
4. Add another layer named `Ocean Texture`. Choose **Filter → Filter Gallery → Texture → Grain** and apply a subtle grain effect. Set the layer blend mode to **Soft Light** and reduce opacity.
5. Create a small star or sparkle on a transparent layer. Select it and choose **Edit → Define Brush Preset**. Name it `Star Scatter`, then use it on a new layer to add stars around the eclipse.
6. Add a text layer with a short caption. Open **Layer Style → Outer Glow** and apply a warm glow.
7. Save the layered project as a PSD.
8. Export the finished artwork using **File → Export → Export As → PNG**, keeping the size at **1200 × 800**.
